## 重点播放验收

1. 正常播放 → 返回首页，重复 30 次；外放、耳机、蓝牙分别检查瞬态爆音。记录设备、iOS、采样率与音频路由。未经真机验证不能宣称原爆音问题已解决。
2. 多 P、合集、番剧、相关视频、听视频分别检查自然结束、手动切换、循环、后台和 PiP；不应重复推进队列。
3. 空降覆盖重叠片段、拖入片段、拖回片段、片尾、倍速、禁用/启用、接口失败。
4. 定时覆盖立即停止、播完当前再停、到点瞬间视频结束、锁屏、后台、重新打开 App、计时期间切视频、手动恢复。
5. 网络切换、超时、已失效 URL、登录失效、账号切换与取消请求均不得恢复已经离开的播放器。

## 完成标准

每个条目同时满足：实际入口、原生业务实现、边界处理、可执行测试或可复现真机验收记录。单纯继承代码、添加按钮、打开网页或声明接口均不算完成迁移。稳定发布前，逐项清单中的未完成项必须全部处理或明确记录为经确认的 iOS 平台差异。

## 离线下载验收

- 12 项核心测试覆盖连播/计时/空降和下载标识、任务代次、暂停后旧回调、双轨完成条件、未知大小进度、索引编码。iOS 下载和合并尚待云端与真机验证。
- 必测：多 P、PGC、不同画质/编码、切后台锁屏、应用被系统终止后重启、暂停立即续传、删除中收到迟到回调、URL 过期、空间不足与合并取消。用户主动强退后 iOS 不保证继续后台任务。
- 下载保存在独立目录，不受普通缓存清理影响。默认禁止蜂窝下载；开关用于新任务。弹幕下载失败不丢弃视频，并允许单独重试。
- 存储损坏时显示错误，不以空列表覆盖原索引。完整下载媒体可通过系统分享导出；批量删除须确认。

- 字段写请求对照原版 `http/user.dart`，使用 App access key 和 Android HD 签名；仅有 Web 登录时允许修改头像并明确提示其他字段的登录要求。头像使用带 CSRF 查询参数的 multipart 请求。
- 写操作校验页面打开时的 MID 和凭据版本，Cookie/CSRF/access key 均取自同一主账号快照，不自动重试结果不明的写入。
- 新增请求契约覆盖签名字段、字面加号、头像 multipart、账号切换和不重复上传。Swift 语法与项目结构检查通过；实际资料修改、照片选择和裁剪手势等待 Xcode/真机验收。

## 关注与粉丝管理增量

- “我的 → 关注、粉丝与黑名单”接入关注分组、全部关注搜索、最近关注/最常访问排序、分页及原生用户空间跳转；UP 主空间的关注/粉丝数量也可进入相应列表。服务端限制或隐私错误原样提示，不声称能读取隐藏列表。
- 自定义分组支持创建、改名、确认删除和手动保存排序；系统分组锁定。为用户设置分组前先读取完整归属，支持多选、特别关注及取消全部后明确写入默认分组 `0`。
- 支持关注/取关、特别关注、确认移除粉丝、加入/移出黑名单；移除粉丝使用原版 `act=7`，不是取消自己的关注。查看他人的列表时不提供分组/粉丝/黑名单管理权限。
- 所有关系读写沿用原版和现有关注按钮的主账号语义，Cookie/CSRF/MID/版本来自同一快照；查询条件在提交时固定，分页不会采用未提交输入。写请求只尝试一次，失败保留编辑和排序。
- 原版核对路径：`http/member.dart`、`http/follow.dart`、`http/fan.dart`、`http/black.dart`、`http/video.dart` 和 `pages/group_panel/view.dart`。新增契约覆盖搜索 WBI、分组分页、默认分组、排序、移除粉丝、系统分组保护和账号切换；Swift 语法/项目结构检查通过，尚待本次 Xcode CI 和账号验收。
