# 功能迁移与验收

目标是迁移 PiliPlus 的 iOS 可用功能；当前是 **0.1 开发版本，尚未实现完整功能对等**。
“已接入”指存在业务实现和调用入口，不等于已经在真实账号、设备和所有内容类型上通过验收。

基线：用户的 PiliPlus 2.1.5 / `a30fcc31043e10cd38c198f47ddd7b23fd6e6163`；并记录 2026-10-05 当前源码的变化。原版 README 的逐项清单见 `PILIPLUS_FEATURE_INVENTORY.md`。

## 重点播放验收

1. 正常播放 → 返回首页，重复 30 次；外放、耳机、蓝牙分别检查瞬态爆音。记录设备、iOS、采样率与音频路由。未经真机验证不能宣称原爆音问题已解决。
2. 多 P、合集、番剧、相关视频、听视频分别检查自然结束、手动切换、循环、后台和 PiP；不应重复推进队列。
3. 空降覆盖重叠片段、拖入片段、拖回片段、片尾、倍速、禁用/启用、接口失败。
4. 定时覆盖立即停止、播完当前再停、到点瞬间视频结束、锁屏、后台、重新打开 App、计时期间切视频、手动恢复。
5. 网络切换、超时、已失效 URL、登录失效、账号切换与取消请求均不得恢复已经离开的播放器。

## 完成标准

每个条目同时满足：实际入口、原生业务实现、边界处理、可执行测试或可复现真机验收记录。单纯继承代码、添加按钮、打开网页或声明接口均不算完成迁移。稳定发布前，逐项清单中的未完成项必须全部处理或明确记录为经确认的 iOS 平台差异。
