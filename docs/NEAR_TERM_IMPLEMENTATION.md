# 近期功能独立开发与模拟器验收

开发分支：`feat/native-near-term-features`，基线 `1a0dd3e`。用户当前没有 IPA 签名环境，本轮以原生代码、模拟器测试和可复现记录交付，实际账号/真机反馈另行跟进。

## 范围与阶段

1. 离线：下载完成校验；收藏夹/稍后再看的所选或全部筛选结果批量缓存；仅音频下载、离线音频播放与导出。
2. 播放器与字幕：防误触/锁定方向；字幕自定义颜色；主/副字幕独立选择与双语同步显示。
3. 账号与网络：独立评论读取账号（含匿名）；测速实时反馈/取消；最佳音质策略与兼容回退。

每阶段提交后调用 `Build, test and publish IPA` 的 `workflow_dispatch`，使用 `simulator_only=true`，运行核心测试、iOS 单元测试、UI 回归和预览，不要求签名也不发布 Release。完整任务仍以最后提交的测试结果为准。

## 离线实现与验收点

- 音频任务只需要 `.audio` 部件，下载地址不包含视频轨。旧下载索引缺少新字段时仍按视频解码；同一 CID 的视频和音频下载可共存。
- URLSession 负责续传拼接。完成时拒绝非 200/206、网页/JSON、空文件、错误 Content-Range 与已知长度不符；最终输出必须可由 AVPlayer 读取且包含期望轨道。
- 收藏/稍后再看全量读取保留提交的筛选条件，防重复分页；逐项解析可用画质/音频流，不超过所选最高画质。账号切换或取消后不继续入队；既有下载保留。
- 离线音频采用音频播放器、系统媒体控制、同类型队列及 M4A/兼容容器无重编码导出。
- 新测试覆盖旧索引、单轨完成条件、响应/文件校验、分页/筛选/去重、账号版本、取消、真实 AVFoundation 音频导出与损坏文件拒绝。阶段 CI 结果在完成后补入。

## 真机反馈边界

模拟器能验证状态、请求参数、文件合并/导出、界面交互；真实登录权限、系统终止后的后台恢复、蓝牙/来电、长时间耗电及不同编解码设备支持需要之后真机复核。不会将上游的 mpv/Flutter 故障直接标记为原生已修复。

## 播放器、字幕、账号与网络

| 功能 | 使用入口 / 行为 | 自动验收 |
| --- | --- | --- |
| 固定全屏方向 | 全屏玻璃锁按钮；设置 → 播放设置可关闭“锁定控件时固定屏幕方向”。记录具体横屏左/右，解锁及离开恢复方向策略 | 协调器拒绝反向/竖屏请求、设置更新不覆盖锁、退出清理；XCUITest 旋转设备并操作锁/解锁 |
| 字幕自定义颜色 | 字幕 → 显示：系统选色器、常用色、重置、实时预览，持久保存 | UI 改色、重启后读回相同颜色；使用实际字幕 Overlay |
| 双语字幕 | 字幕 → 双语字幕：主/第二轨独立选择。在线、导入及离线均支持，第二语言单独导出 | 不同断句时间、单轨/AI 默认策略、去重、切换与重置、持久偏好和 VTT 导出 |
| 独立评论读取账号 | 设置 → 隐私 → 多账号用途分配实验 → 评论读取：跟随互动 / 主账号 / 指定 / 匿名 | 列表/回复/对话请求 Cookie，写入仍绑定互动账号；旧请求结果丢弃。不同读取账号的赞/踩标记不冒充互动账号状态 |
| 直播 CDN 测速反馈 | 直播播放器 → 播放诊断 → 直播线路测速。显示当前阶段、字节量、采样速度及完成数；可取消或在测完后手动使用线路 | HLS 播放列表解析到媒体段、限定采样量、不转发账号凭据、取消正在进行的 URLSession 请求。最多测 12 条，每条最多采样 256 KiB |
| 最佳可用音质 | 设置 → 播放设置 → 默认音质 / 蜂窝网络音质。兼容 AAC 为原默认；最佳策略优先无损，其次杜比，再 AAC。听视频手动选轨优先 | 缺轨回退、Wi-Fi/蜂窝设置分离与持久化、高音质失败时音轨替换不改变视频画质且播放器标识更新 |

最佳音质只选择接口实际返回且播放器支持的音轨，不绕过会员或内容权限。普通视频发生高音质回退后，同一视频分 P 后续切流保持兼容音轨；切换视频/分 P 后重新按设置选择。设置修改用于后续取流，已入队音频任务保持所选音轨，取不到时明确报错。

直播测速是有上限的短时媒体采样，用于比较当前线路；不是持续带宽测量，不自动替换播放线路。取消保留已完成结果，退出诊断页或线路列表改变时停止采样。
