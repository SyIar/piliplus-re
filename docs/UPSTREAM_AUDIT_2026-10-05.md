# 2026-10-05 源码对比与本轮交付

对比原生仓库基线 `8bb575b` 与 PiliPlus `7a4f442f450ff0698d0fbe5cecb9666cd1c12e3f`（2.1.5）。这是 Swift/AVPlayer 与 Flutter 两套实现的业务对照，不能按文件数量或 README 勾选判断完成度。未逐项核验的条目仍保留在 [原版清单](PILIPLUS_FEATURE_INVENTORY.md)，本轮不宣称全部功能对等。

## 本轮实现

| 模块 | 可见变化 | 核心源码与验证 |
| --- | --- | --- |
| 首页 | 推荐/热门标题菜单、投屏与消息玻璃胶囊、账号头像、独立圆形搜索入口、封面下作者头像与元数据 | `RootTabView` 的原生 search role、`HomeFeedNavigationChrome`；实际首页明暗截图 |
| 横屏播放器 | 标题/作者，分享与投屏/设置工具组，中央播放与前后 10 秒/上下集，底部字幕/弹幕/定时/队列/收藏，细进度胶囊与锁定 | `PiliGlassFullscreenControls` 接入 `VideoDetailShellSurfaceHost`；`PiliLiquidGlassUITests` |
| 玻璃材质 | 清透材质、细边缘高光和弱阴影；系统减少透明度时使用实体背景，增强对比度时加粗边界 | `PiliLiquidGlass`；保留系统浅色/深色选择 |
| 详情工具 | 下载、投屏、字幕、笔记等收纳为横向胶囊，减少竖向按钮堆叠 | `VideoDetailSummaryCard`；所有按钮连接既有功能 |
| 评论管理 | 点踩/取消点踩、删除、UP 置顶/取消置顶、举报；视频/动态/楼中楼共用 | `BiliAPIClient+PiliCommentActions`、`PiliCommentActionsView`、`PiliCommentActionStore`；权限/请求契约/失败回退测试 |
| 聊天设置 | 服务端允许时显示内容推送开关；读取真实免打扰状态；关闭推送前确认 | `BiliAPIClient+PiliChatSettings`、`PiliChatSettingsView`；请求参数与账号切换测试 |

同时修正在线、离线和横屏字幕列表的时间跳转：字幕返回秒数，不再把秒数误当作 0–1 播放比例。

模拟器验收还修正了分离搜索入口在明暗切换后保留旧材质的问题；横屏遮罩铺满视频表面，导出预览按实际横屏方向展示。

评论写入使用「互动账号」，聊天设置使用「主账号」。请求携带该账号的 Cookie/CSRF，菜单保留账号版本；账号变化后的旧操作会拒绝，网络错误不自动重复写入。举报不会顺带拉黑。点赞与点踩互斥，失败保留成功前状态；删除与置顶成功后刷新原列表。

## 已存在，不应重复算作缺失

- 私信图片、撤回、删除会话、置顶、免打扰：`AccountMessageService.swift` 和 `AccountPrivateMessageViews.swift` 已有接口与入口。
- 多账号、收藏夹批量管理、关注分组、个人资料、历史/稍后再看：已有原生业务实现，前一轮 `8bb575b` 完整 CI 通过；真实账号验收仍需单独进行。
- 听视频、离线下载、DLNA、字幕、互动分支和文本笔记：已有实现，但下表列出的细项尚不对等。
- SuperChat：`LiveDanmakuService` 已解析 `SUPER_CHAT_MESSAGE`，不能称整个模块不存在；专用展示与完整交互仍需核对。

## 确认仍有缺口

| 原版功能 | 当前缺口与源码依据 |
| --- | --- |
| 动态发布/编辑/删除/置顶、转发、投票与话题选择 | `BiliAPIClient+Dynamic` 为读取，`+Interactions` 仅有动态点赞；尚无完整发布与管理链路。评论编辑器不能当作动态编辑器 |
| 全局消息设置、折叠消息、分享视频/番剧/动态/专栏/直播到私信 | 上游 `grpc/im.dart`、`whisper_settings` 等已覆盖；原生私信服务尚未接入对应全局配置、分组列表或内容卡片发送 |
| 评论楼中楼热度/时间切换 | 原生有楼中楼和查看对话，但缺少排序选择及对应请求切换 |
| 弹幕悬停、点赞/举报，高级弹幕 | 当前弹幕渲染未接入原版的选择交互和高级模式；新增评论点踩不等于弹幕交互 |
| 课堂视频、追番状态、合集订阅 | PGC/合集已有播放与浏览；课堂专用播放、追番状态管理、订阅/退订写入尚缺 |
| 截图、GIF、Live Photo、超分、AI 原声翻译 | 没有完整原生导出/处理链路；字幕和普通离线视频导出不能替代这些能力 |
| 手动 Cookie 登录、搜索用户动态 | 已有 Web 会话 Cookie 保存和空间动态分页，尚无对应的粘贴登录与动态关键词搜索入口 |
| 图文/专栏 | 动态可展示图文，但专栏原生正文、用户独立图文列表不完整 |
| 离线与 DLNA | 上游本次增加 offline ugc season；原生有多 P/队列，但整合集批量离线、后台投屏与自动切集仍需补齐 |
| 笔记与字幕 | 笔记完整富文本/图片/跳转标签、字幕未登录 gRPC 兜底/PiP 等尚缺 |

Android/Windows/Linux 和 Android 专属音效不属于这个 iOS 原生工程的可直接迁移平台能力。平台差异与尚未实现的 iOS 功能分开记录。
